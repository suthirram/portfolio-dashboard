# Login sunrise artwork

`login-sunrise.webp` was prepared from the owner-provided
`Muted Sunrise Finance Dashboard Login.png` with the built-in imagegen tool.
The sample login card was removed so the page can render accessible HTML
controls. The result was encoded as WebP with `cwebp -q 88` (99,706 bytes).

Final imagegen prompt:

> Use case: precise-object-edit. Asset type: full-bleed website login background.
> Edit target: provided Muted Sunrise Finance Dashboard Login reference.
> Remove the entire white login card and every UI control/text inside the card
> from the right-hand side, filling the removed area with the existing pale
> lavender sunrise sky and subtle flowing blue lavender ribbons. Preserve the
> exact left-hand composition of Bombay stock exchange building, New York
> stock exchange facade, teal polygon bull, warm peach polygon bear,
> candlesticks, glowing digital globe, and muted sunrise. Keep original wide
> 16:9 framing and pale dreamy colors. Rightmost 40 percent should be spacious
> pale lavender negative space for a real HTML form overlay. No UI cards, no
> input fields, no buttons, no labels, no new text. Preserve architectural
> lettering naturally.
