Visual spec PD-047 PRD-004 · DD-004 Portfolio Dashboard

All-transactions view

One dashboard button opens every past ledger event across every holding — newest first, filterable, with every field the add/edit transaction modal accepts visible in the row. These frames are the visual contract for PD-047; they are rendered in the app's own design tokens, not an approximation of them.

Why this is HTML and not a Figma file

There is no Figma account wired into this project, so this document is the design deliverable in its place: the same role a Figma frame set plays — labelled artboards, annotations, state coverage — authored against the real token file.

Every colour, radius, and type size below is read from frontend/src/styles/tokens.css. The theme switcher above swaps between the three shipped palettes. A mockup that drifts from the tokens is worse than no mockup, so nothing here invents a value; the frames use the .btn, .card, .page-nav and .nav-glass rules the app already ships.
