1. Owner decisions reflected here

Keep the original sidebar

Retain its position, proportions, appearance and mobile drawer. This later owner decision supersedes the draft shell’s top-navigation illustration. No Ambient control or command palette.

One interface per account

Super admin chooses Classic, Glass or UI_2.0. User and regional Admin views do not gain feature, role or Branding controls. Cyber remains premium-only.

Complete overall valuation

INR + EUR converted at the stored daily rate + physical gold. Missing required FX or gold valuation is unavailable, never zero or a cost-price substitute. Re-fetch is user-triggered.

Keep financial workflows

Dialogs hold breakdowns and holding actions. Investment delta stays inline. Imports keep their parsers and load header-only examples. All 15 Gold columns remain visible by default.

    5. Review and verification limits

    • Shipped palette tokens are embedded verbatim. The original mockup layout is retained, and theme selection is passed explicitly into the artboard.
    • No automatic external requests, account writes, production data, historical-rate fetching, migrations or backend calculations run from this file.
    • The embedded preview uses Sep–Nov 2026 fixtures, simplified import validation and the original small Gold price-gap example. These are not normative financial logic or production window sizes.
    • Additional Google Fonts are named for design review. Offline samples use system fallbacks; use the online-capable local handoff to compare downloaded faces.
    • Browser-session interactions and JavaScript syntax can be checked independently. Native browser appearance, focus return, reduced-motion rendering and live API behavior are not claimed as verified when browser permission is unavailable.
    • Production implementation must reuse existing hooks, parsers, the Go ledger, permissions and the shared component registry, rather than copying demo calculations or arrays.
