The app in the shell (live)

click anything · ⌘K / Ctrl+K

Sidebar on every signed-in page, the page header as a floating toolbar, the dashboard hero above the cards. Click the nav, Refresh (a toast, not an alert), Add holding, or press ⌘K / Ctrl+K inside the frame. Flip Glass UI off above to see the current UI that every other account keeps.

Hero (DD-011 §6): current value, today per currency with its % (snapshot close first, else Yahoo), unrealised, INR/EUR split. Toggle TCS has no close: Today · INR becomes “—”, EUR stays.
Header copies hidden (DD-011 §4): brand, page links, theme picker, user menu are in the sidebar, so the toolbar keeps only the title and page actions.
Phone: the sidebar folds into a bottom tab bar; “More” opens the palette.
2

Admin → Users: the switch

The super admin flips Glass UI on / off per account (PUT /admin/users/{id}/ui-revamp). Flipping root (you) changes this frame at once, like the real session refresh; others get a toast.

3

Command palette matching (playground)

Every word must appear in the label, group or keywords (the same matchCommands the frame runs). ↑/↓ move, Enter runs, Esc closes.
